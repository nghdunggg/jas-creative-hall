# ✦ Jasverine's Creative Hall — v3

## Files to deploy
Upload these to your GitHub repo (keep folder structure):
```
index.html
ideas/
  manifest.json
  images/           ← auto-populated when you upload images
```

## Setup (same as before)
1. Create public GitHub repo
2. Enable GitHub Pages → Settings → Pages → branch: main
3. Create token at github.com/settings/tokens (scope: repo)
4. On the site: click ⚙ Settings → enter username, repo, branch, token

## What's new in v3
- ✏ Edit any idea (click pencil icon on hover)
- 🗑 Delete idea (click trash icon, confirm dialog)
- ✦ Two view modes: List ☰ and Block ▦
- 🔗 References section per idea
- 🖼 Image upload (cover + content blocks)
- 📝 Notion-like block editor (Text, Heading, Quote, Divider, Image)
- 🗂 Categorized view groups ideas by category
- ➕ Add custom categories with emoji
- 🔎 Search + sort (newest/oldest/A-Z)
- 🐛 Fixed "Add Idea" button (template literal bug resolved)
